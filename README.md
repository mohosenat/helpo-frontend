# 🌱 Helpo | Helping Hands, Stronger Communities

Helpo is a community-driven social development platform that connects people who want to make a positive impact in society. Users can create social service events, participate in upcoming events, and contribute to making their communities better.

🌐 **Live Website:** https://helpo-frontend.vercel.app/

---

## ✨ Key Features

- **Authentication System:** Secure registration and login with Email & Password and Google OAuth.
- **Explore Events:** Discover upcoming social development events.
- **Event Details:** Explore event descriptions, schedules, locations, and other important information.
- **Create Events:** Authenticated users can organize and publish their own social initiatives.
- **Manage Events:** Update or delete events created by the logged-in user.
- **Join Events:** Participate in community events with a single action.
- **Joined Events:** Keep track of all events you have joined.
- **User Profile:** View and update personal profile information.
- **Protected Routes:** Restrict private pages to authenticated users.
- **Responsive Interface:** Enjoy a consistent experience across mobile, tablet, and desktop.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/mohosenat/helpo-frontend
```

**2. Navigate to the project**

```bash
cd helpo-frontend
```

**3. Install dependencies**

```bash
npm install
```

**4. Setup environment variables**

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
NEXT_PUBLIC_AUTH_URL=http://localhost:5000
```

**5. Start the development server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
